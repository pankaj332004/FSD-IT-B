# OS Model Simulator

A comprehensive interactive simulator for understanding Operating System concepts including CPU Scheduling, Memory Management, and Disk Scheduling algorithms.

## Features

### CPU Scheduling
- FCFS, SJF, Round Robin, Priority Scheduling
- Metrics: Turnaround Time, Waiting Time, Completion Time

### Memory Management
- First Fit, Best Fit, Worst Fit Allocation
- Metrics: Fragmentation, Allocation Status

### Disk Scheduling
- FCFS, SSTF, SCAN, C-SCAN Algorithms
- Metrics: Seek Time, Head Movement

## installation

**Backend:**
```bash
cd assignment2/os_modelBack
npm install
npm start
```

**Frontend:**
```bash
cd assignment2/os_model
npm install
npm run dev
```

## Architecture

- Frontend: React + Vite
- Backend: Node.js + Express
- Backend runs on port 5000
- Frontend runs on port 5173
